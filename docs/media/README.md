# README media

What the root README displays. Nothing else reads this directory.

The wordmark ships twice because GitHub serves a `<picture>` by colour scheme:
the light file is the original, and the dark one recolours the black half to
white. A single file would have to pick one, and the original's black "Model"
is unreadable on a dark background.

The three demos are the routing claim rather than decoration — one app, one
effort setting, three questions, three different models — and the badge in the
corner of each reply is the app naming the model it actually called.

`routing-vs-single-model.jpg` is plotted by `plot_model_scores.m` in the
vals-index analysis; its numbers are the ones quoted in the README.
